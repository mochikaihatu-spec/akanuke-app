# フェーズ1 設計: 憧れ → あなた専用の行動プラン(MVP 前半)

承認済み(2026-10-27)。実装はこの順で小さく進め、各ステップの完了基準を満たしてから次へ。

## 方針
- AI は **JSON(内容)だけ** を返し、画面は固定の UI で描画する。AI に画面を作らせない。
- プランは **保存して再表示**。表示のたびに AI は呼ばない(料金を抑える)。
- 作り直しは **確認ダイアログ必須**。前のプランは `archived` として履歴に残す。承認済みプランを黙って変えない。
- 既存機能(食事・体重・筋トレ・美容相談)はそのまま残す。再構成はフェーズ4。
- 新しい `/api/*` は「入力チェック → `checkAiAccess(kind)` → `withSafetyRules(prompt)`」の順(CLAUDE.md 参照)。

## 画面
### `/onboarding`(ヒアリング)
| 質問 | 必須 | 入力 | 保存先カラム |
|---|---|---|---|
| 憧れの雰囲気 | ○ | 自由入力(100文字)+例ボタン(K-POPアイドルっぽい/韓国っぽい透明感/清潔感のある大人/ナチュラルでおしゃれ) | `ideal_text` |
| 取り組みたい部分 | | 複数選択: 髪・眉・肌・メイク・服・姿勢・体型・清潔感(「全部やらなくてOK」と明記) | `focus_areas` |
| 悩み | | 自由入力(500文字) | `concerns` |
| 1か月の予算 | | 3000 / 5000 / 10000 / 20000 / 気にしない(none) | `monthly_budget` |
| 1日に使える時間 | | 5 / 15 / 30 / 60 分 | `daily_minutes` |
| 好み・生活 | | 自由入力(500文字) | `preferences` |

### `/plan`(マイプラン)
要約+雰囲気キーワード → 要素ごとの優先順位(理由・行動・所要時間・目安費用)→ 費用合計(アプリ側で計算し予算と並べる)→ 週間プラン(7日)→ 注意書き。「プランを作り直す」は確認後に新規生成。
ホームにカード(プラン無し: 作成導線 / 有り: 要約)。下タブ「プラン」をホームの次に追加。

## データ(013_add_ideal_profiles_and_plans.sql)
- `ideal_profiles`(user_id 主キー): 上表のカラム + `updated_at`。
- `plans`: `id`, `user_id`, `status`('active'|'archived'), `ideal_snapshot`(生成時の答えのコピー), `content`(AI の JSON), `created_at`。使用中は 1 人 1 つ(部分ユニークインデックス)。
- RPC `save_new_plan(p_ideal_snapshot, p_content)`: 前の active を archived にして新規 insert(security invoker=RLS が効く)。直接の削除はできない。
- どちらも RLS「自分の行だけ」+ `on delete cascade`(アカウント削除で消える)。
- ミッション/完了記録の表はフェーズ2で追加。

## AI の出力形式(`content`)
```
summary: string(40文字程度)
vibe: { title: string, keywords: string[3〜5] }
elements: [2〜5件]
  { area: 髪|眉|肌|メイク|服|姿勢|体型|清潔感, priority: 1〜3 | null, why: string,
    actions: [1〜4件] { title, detail, minutes: number, cost_yen: number|null, frequency: string } }
weekly: [7件] { day: 1〜7, area, task, minutes }
notes: string(注意書き1行)
```
- サーバー(`src/lib/plan-schema.ts`)で形・件数・文字数・数値・`area` の許可リストを検査。壊れていたら保存しない。
- 費用合計はアプリ側で計算(AI の計算は信用しない)。表示時も防御的に描画(React のテキスト描画=エスケープ)。
- `max_tokens` は 3000(JSON が途中で切れないよう余裕を取る)。

## AI への追加ルール(共通の安全ルールに加えて)
憧れの人物名をそのまま繰り返さず「雰囲気をつくる要素」に言い換える/現在の容姿を評価しない/予算と時間を必ず守る/皮膚科・美容医療が必要そうなら「専門家に相談」とだけ書く/選ばれた部分を中心にし、全部をやらせない。

## 回数制限
`AI_DAILY_LIMITS` に `plan: 3`(1日3回)を追加。表示は AI を使わない。入力上限は DB の check 制約とサーバー検査の両方で守る。
