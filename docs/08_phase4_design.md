# フェーズ4: ホーム・ナビゲーション・デザインの改善(2026-10-28)

## 目的
「記録アプリ」から「憧れを、あなた専用の行動プランに。」のコーチ型サービスへ、見た目と導線を合わせる。スマートフォンで使いやすく、続けたくなる UI にする。

## ナビゲーション(下部タブは4つ)
| タブ | 行き先 | 「いまの画面」とみなす場所 |
|---|---|---|
| ホーム | `/` | `/` |
| マイプラン | `/plan` | `/plan`、`/onboarding` |
| AI相談 | `/ai`(新) | `/ai`、`/chat`、`/beauty`、`/plan/consult` |
| 記録 | `/records`(新) | `/records`、`/meals`、`/weight`、`/workout` |

- プロフィール・設定は、ホーム右上のアイコン(`/profile`)と、記録ページの下から。
- 既存の URL・機能はすべて残した。食事・体重・写真解析・筋トレは「記録」から、美容相談・食事チャット・プラン調整は「AI相談」から辿れる。
- 以前の「筋トレ/美容」のタブ表示切り替え(機能のON/OFF)は、タブがなくなったため、筋トレは記録ページの表示にだけ反映している(美容相談は常に表示)。

## ホームの構成(上から)
1. ヘッダー(AKANUKE / 憧れに、一歩近づく。 / プロフィールアイコン)
2. 今日のミッション(`MissionCard`。完了・お休み・戻す。プラン未作成・ミッションなし・読み込み中の表示あり)
3. あなたの垢抜けメニュー(マイプラン / プランを調整 / AI美容相談 / 成長の記録)
4. 今週の進捗(`WeekProgress`。実際の記録だけから計算。架空の数字は出さない)
5. きょうの記録(ToDo・カロリー・タンパク質・体重など、従来のカードを下に移動)+「食事を記録する」

ミッションとプランと記録は `HomeCoach` が1か所で読み込み、完了すると進捗も同時に更新される。ホーム専用の重複したミッション管理は作っていない。

## デザインの土台(`src/app/globals.css`)
- 既存画面は `slate-*`(ニュートラル)と `blue-*`(アクセント)のクラスで書かれているため、**色の定義を差し替える**ことでアプリ全体を統一した(画面ごとの書き換えは不要)。
  - `slate` = 温かみのあるニュートラル(背景 #F7F5F1、文字 #29252E)
  - `blue` = ラベンダー(ボタン・リンク #6F5B91、飾り #8B77A9、淡い面 #EAE3F1)
  - 補助色: `sage`(セージ)/ `coral`(コーラル)/ `sand`(サンド)。機能カードの区別だけに使う。
- 指定された #8B77A9 は、白文字との比が 3.96 で基準(4.5)に届かないため、ボタンと文字には #6F5B91(5.86)を使い、#8B77A9 は飾りに使う。元の薄い灰色の文字(2.56)も #6E6874(5.4)に濃くした。
- 文字は日本語向けのフォント指定に。`<html lang="ja">`。
- 共通部品: `icons.tsx`(同じ系統の線画)、`FeatureCard`(tile / row)、`MissionCard`、`WeekProgress`。
- 新しい画面を作るときは、これらの色・部品を使う(新しい色を足さない)。
