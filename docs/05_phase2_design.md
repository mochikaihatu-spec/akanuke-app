# フェーズ2 設計: 今日のミッション + 完了記録 + 進捗(2026-10-28 承認・おまかせ)

## 方針
- **AI を使わない**。今日のミッションは、保存済みプランの `weekly`(7日分)から取り出す。料金も回数制限も増えない。
- 責めない設計: やらなかった日は空白のまま(「できなかった」と表示しない)。完了時の一言は固定文(AI ではない)。

## ルール
- **何日目か**: プラン作成日(日本時間)を1日目とし、7日ごとに繰り返す(8日目=1日目のミッション)。プランを作り直したら、新しいプランの作成日から数え直す。
- **ミッションは1日1つ**(その日の `weekly` の1件)。状態は `done`(完了)/ `rest`(お休み)。完了後は「戻す」で取り消せる。
- **連続日数**: 今日(未記録なら昨日)から過去へ、記録(done/rest)がある日が続く間は続いているとみなす。数える値は `done` の日数のみ(お休みは途切れさせないが増えない)。記録のない日で途切れる。
- **今週**: 今の7日サイクル(プラン作成日から7日ごと)の `done` 数 / 7。
- 通知(リマインド)は今回は入れない。

## データ(015_add_mission_logs.sql)
`mission_logs`(user_id, plan_id, mission_date(日本時間), day_index, area, task(コピー), minutes, status, created_at)。`unique(user_id, mission_date)`。RLS: 自分の行だけ、`plan_id` も自分のプランのみ。アカウント削除で cascade 削除。

## 画面
- **ホーム**: `MissionCard`(今日のミッション・完了/お休み/戻す・今週 X/7・連続日数)。プランの要約カード(`PlanCard`)はその下。
- **マイプラン**: 週間プランに今日のバッジと完了✓/お休み印。上に進み具合(今週・連続・合計・部位別)。

## 実装の構成
- `src/lib/mission.ts`: 純粋な計算(何日目か・今日のミッション・連続日数・今週の集計)。`npm test` で検査。
- `src/lib/use-missions.ts`: 記録の読み込みと保存(完了・お休み・戻す)。
